# Telegram-бот залишків МойСклад

Бот вивантажує склад і продажі з API МойСклад. У ньому немає Claude і немає 1С. Цифру на екран ставить відповідь МойСклад, а не модель.

Кнопка «Остатки» питає звіт `https://online.moysklad.ru/api/remap/1.2/report/stock/all`. Код групує рядки за папкою товару і показує назву, залишок у штуках і ціну. Можна відкрити одну категорію або всі залишки. Список категорій на клавіатурі теж будується з цього звіту.

Кнопка «Продажи» за обраний період питає два звіти: `report/sales/plotseries` (сума і кількість чеків) і `report/turnover/all` (скільки штук пішло по товарах). У меню періоди: сьогодні, вчора, позавчора, цей тиждень, цей місяць, минулий місяць.

Якщо API не відповів, код повідомляє про помилку з’єднання і не підставляє залишок. Бот відповідає лише тим Telegram ID, які записані в списку `users`. Іншим пише, що доступу немає.

## Стек

- Python
- aiogram 2.25
- requests
- API МойСклад remap 1.2

## Запуск

У папці `main` створіть `config.py` і запишіть туди токен МойСклад, токен Telegram і список id:

```python
token_ms = "токен МойСклад"
token_tg = "токен Telegram"
users = []
```

Токен МойСклад береться в кабінеті сервісу або через його API. Токен бота видає BotFather. Далі залежності з `requirements.txt` і запуск `main/bot.py`. У репозиторії є `Dockerfile`.
